# Agent Prompt Templates

这里不是原始角色提示词备份，而是从原始 `.trae/agents` 中提炼出的可复用模式。

原始 prompt 中包含大量私人角色设定、剧情状态和成人/私人变体，不适合默认上传公开仓库。这里保留的是更通用的 agent 架构：

- `research-agent.md`：搜索、核实、截图留证。
- `data-viz-agent.md`：数据可视化 agent，优先用代码出图。
- `tool-router-agent.md`：按任务选择 MCP 工具。
- `workmode-memory-pattern.md`：角色/干活双模式和 memory 载入模式。
