# Critical Thinking - 科学论证批判性分析

## 何时触发

- 用户说"分析一下这篇论文的论证逻辑"
- 精读一篇论文后需要评估它真正证明了什么、没证明什么
- 综述中需要比较不同研究的证据强度
- 审稿时发现结论和数据之间似乎有跳跃，需要系统排查

## 分析框架：Claims & Evidence Map

把论文拆成一个个 claim-evidence 对，逐对检查：

### 识别论点 (Claims)
论文里每个以句号或结论语气结束的陈述都可能是一个 claim。重点是：
- 作者**明确声称**的结论
- 作者**暗示但没有明说**的推论
- 摘要和讨论里总结性的话

### 识别证据 (Evidence)
每个 claim 对应的支撑数据：
- 图/表的定量结果
- 引用的前人工作
- 统计检验结果
- 作者未提供的证据标注为"缺失"

## 论证质量检查

对每个 claim-evidence 对逐条打分：

### 1. 相关性 (Relevance)
证据是否直接支持这个 claim？还是只间接相关？
- ✓ 直接：干预组的 A 指标测的就是 claim 里的 A
- ✗ 间接：claim 说"抑制肿瘤"，但证据只测了"细胞增殖"

### 2. 充分性 (Sufficiency)
光有这个证据够不够推出这个 claim？
- 样本量够吗？
- 独立性够吗（生物重复 vs 技术重复）？
- 只有一个实验还是有正交验证？

### 3. 替代解释 (Alternative Explanations)
除了作者的 claim，还有别的解释吗？
- 技术假象（抗体交叉反应、PCR 污染、批次效应）
- 牵强关联（A 和 B 相关不等于 A 导致 B）
- 幸存者偏差或其他选择偏倚

### 4. 泛化范围 (Generalizability)
结论能推到多远？
- 只在一个细胞系 → 不推全体
- 只在小鼠 → 不推人类
- 只在特定遗传背景下 → 不推其他

## 常见论证谬误速查

| 谬误 | 论文里的表现形式 |
|------|------------------|
| 以偏概全 | 在 HeLa 细胞里做了实验，讨论写成"在所有肿瘤中..." |
| 因果倒置 | 癌组织里 A 基因高表达 → 推论 A 导致癌症 |
| 忽略竞争假设 | 敲低 A 看到表型变化，不讨论脱靶效应 |
| 选择性报告 | 只报告显著的结果，未提及做了什么检验 |
| 循环论证 | 用 A 定义 B，又用 B 证明 A |
| 稻草人 | 把前人工作歪曲成一个容易攻击的假说 |
| 证据不足 | 从 n=3 没统计检验，得出"两组有显著差异" |
| 没有阴性对照 | 声称"药物抑制了增殖"但与 untreated 比，不与 vehicle 比 |

## 工作流程

### 第一步：提取核心 claim
从摘要和讨论里摘出作者最核心的 1-3 个 claim。

### 第二步：映射证据
每个核心 claim 下面找出支撑它的图/表/引文。

### 第三步：逐对检查
用四个维度（相关性/充分性/替代解释/泛化范围）逐个评估。

### 第四步：给出总体证据强度

| 等级 | 含义 |
|------|------|
| 强 | 多个正交实验一致支持，统计学严谨，替代解释被排除 |
| 中 | 证据直接相关，但缺少正交验证或样本量偏小 |
| 弱 | 证据相关但不够充分，或存在未排除的替代解释 |
| 无效 | 证据与 claim 逻辑断裂，或存在明显论证谬误 |

## 输出格式

```markdown
## 批判性分析报告

**论文**: [标题]  
**核心论点**: [作者最想让你相信的那句话]

### Claims & Evidence Map

#### Claim 1: "[原文或转述]"
- **证据源**: Figure X / Table Y / 引用[Z]
- **相关性**: [直接/间接/无关]
- **充分性**: [充分/不足/缺失]
- **替代解释**: [有/无，列出]
- **泛化范围**: [合理泛化 / 过度推广]
- **论证谬误**: [有/无，类型]

#### Claim 2: ...

### 总体证据强度: [强 / 中 / 弱 / 无效]

### 总体评价
[用 3-5 句话总结这篇论文真正证明了什么、没证明什么、需要补什么实验]

### 后续验证建议
- 最关键的验证实验: [一句话]
```
