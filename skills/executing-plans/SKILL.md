# Executing Plans - 按计划执行

## 何时触发

- 已有写好的执行计划（writing-plans 的输出）
- 用户说"按计划执行"
- 需要在独立会话中分批实现

## 工作流程

### 第一步：加载计划
- 回顾完整的执行计划
- 确认当前处于哪个步骤
- 确认本批次要完成的步骤范围

### 第二步：逐批执行
每批执行遵循以下循环：
1. 做该步骤的工作
2. 完成后运行验证（测试、lint 等）
3. 向用户报告进度
4. 等待用户确认再继续下一批

### 第三步：检查点
在每个批次结束后：
- 标记已完成步骤
- 展示当前进度（如 "3/7 已完成"）
- 询问用户是否继续

## 输出格式

```
## 当前进度: 步骤 2/5

### 刚完成: 步骤1 - 创建数据模型
✅ 已创建 model.py
✅ 已通过单元测试

### 即将执行: 步骤2 - 实现 API 接口
预计修改: api/routes.py

继续执行吗？
```

## 核心原则：分批执行，每批验证
