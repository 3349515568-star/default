# Scientific Schematics - 科研示意图设计

## 何时触发

- 用户说"帮我设计一个 Graphical Abstract"
- 需要画信号通路/分子机制示意图
- 论文需要一张总结整个研究的机制图
- 实验设计需要可视化分层结构
- lit-agent review 输出需要配一张总结图

## 与 mermaid-diagrams 的分工

| 需求 | 用哪个 skill |
|------|-------------|
| 流程/步骤/筛选/时间线 | mermaid-diagrams |
| 信号通路/分子机制/细胞结构 | scientific-schematics（这个） |
| 技术路线图 | 两者结合：流程图用 mermaid，节点说明用本 skill |
| 图形摘要 (TOC) | scientific-schematics |

## 示意图类型

### 1. Graphical Abstract (TOC 图)
期刊要求的一图胜千言。**一个核心发现 + 一个核心方法 + 一个箭头**就是最简单的 TOC 图。

设计公式：
```
[干预/处理] → [核心发现] → [生物学意义]
```

### 2. 信号通路图 (Signaling Pathway)
分子间的激活/抑制关系。从上到下或从左到右排列：
- **受体**在最上/最左
- **核心信号分子**在中间
- **下游效应**在最下/最右
- 箭头（→）表示激活，T 形线（⊣）表示抑制

### 3. 实验流程示意图
用图片和箭头展示完整实验 pipeline。比纯文字好 10 倍。

### 4. 机制模型图 (Model Figure)
论文最后一图，总结全篇提出的新机制模型。

## AI 生成示意图的途径

### 方案 A：用 AI 画图工具生成（质量最高，但要有相应 MCP）
```

用自然语言描述图的内容，调用 mcp_ofox-image / mcp_seedream 生成
```

### 方案 B：代码出图（可控性最强，但费时）
```python
# matplotlib 画机制图
# 或 matplotlib + matplotlib.patches 画细胞/分子形状
```

### 方案 C：ASCII/Unicode 草图 → 专业工具细化
先出一个文字草图，用户确认后用 Illustrator/Inkscape 自己画。

## 科学插图设计规范

### 配色
- 最多 5 种颜色，优先 Okabe-Ito
- 用颜色编码功能：红色=激活，蓝色=抑制，绿色=通路核心分子
- 避免红绿配对（对红绿色盲不友好）

### 排版
- 字体统一 Arial/Helvetica，正文 ≥ 8pt
- 标签对齐一致（左对齐或居中，不要混）
- 箭头粗细一致，不超过 2 种箭头类型

### 层次
- 背景浅色区域表示亚细胞定位（细胞膜/细胞质/细胞核）
- 前景深色形状表示分子
- 关键发现用最醒目的颜色或加粗边框

### 可访问性
- 不仅靠颜色区分类别，也用形状差异（圆 vs 方 vs 菱形）
- 箭头类型不同带不同含义时加图例
- 用 add_panel_label（来自 plotkit）加面板字母

## 文字描述模板

当用户没有参考图，需要从文字生成示意图时，用这个模板描述：

```
图类型: [TOC图 / 信号通路 / 机制模型 / 实验流程]
画面分区: [细胞膜 / 细胞质 / 细胞核 / 胞外]
关键元素:
  - [分子/结构名] (位置, 颜色, 形状, 标签)
  - ...
关系连线:
  - [A] → [B] (激活, 红色箭头)
  - [C] ⊣ [D] (抑制, 蓝色T形线)
  - [E] ←→ [F] (相互作用, 双箭头)
标注:
  - 图例位置: [右下/左上]
  - 面板标签: [A/B/C/D]
目标期刊: [Nature/Science/Cell, 单栏/双栏]
```

## 生成流程

1. **确认图类型和核心信息**（这张图要讲的最多 3 件事）
2. **输出文字描述模板**（让用户确认内容）
3. **生成图片**（调用相应 MCP 或给出代码）
4. **用户审核**并迭代

## 连接 lit-agent

- lit-agent review 输出的主题综述段落可以直接提炼成机制图的文字描述
- 用 plotkit 的 journal widths 确保图尺寸符合目标期刊
- 用 add_panel_label 统一加面板字母
